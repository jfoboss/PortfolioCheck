# ИИ-сводки

- **Провайдеры** — `ai.PROVIDERS`: `openrouter` (по умолчанию), `claude`, `qwen`, `openai_compat`, `ollama`.
  Запросы — `_chat()` → `_post()`; ответ модели всегда JSON, разбор — `_extract_json()` (терпим к обёрткам).
- **Модель по умолчанию для OpenRouter** — не константа: `default_model()` берёт первую рекомендуемую
  бесплатную из кэша каталога (`openrouter_models.json`, `CATALOG_DIR` задаёт окно). Бесплатные модели
  OpenRouter снимает без предупреждения. Константа в `PROVIDERS` — только запасной вариант.
- **Рекомендации ★** — эвристика в `parse_openrouter_models`: семейство из `GOOD_FAMILIES`, контекст ≥ 32k,
  бесплатная или дешёвая. Это не результат тестирования моделей — не выдавай её за таковой.
- **Лимиты.** `:free`-модели: 20 запросов/мин и 50/сутки на аккаунт (1000/сутки после покупки кредитов от $10);
  лимит общий для всех бесплатных моделей. `_describe_429` различает `daily` / `minute` / `upstream` / `other`
  по телу ответа и заголовкам. После `daily` выставляется `RATE_BLOCK_UNTIL` — запросы к `:free` не уходят до
  сброса; блокировка сохраняется в `cache/ai_rate_block.json` (`set_rate_block` / `load_rate_block`) и переживает
  перезапуск.
- **Экономия запросов.** Сводки по экранам идут одним запросом (`exec_summary_batch`, промпт
  `EXEC_BATCH_SYSTEM`); обновление тратит 2 запроса: новости + все экраны. Новую ИИ-функцию сначала попробуй
  встроить в существующий пакетный запрос.
- **Кэш `ResponseCache`** (`cache/ai_responses.json`, один файл на все виды сводок): ключ → `{at, fp, data, structural}`;
  последние готовые сводки экранов дополнительно лежат в `cache/exec_<экран>.json` для мгновенного показа при старте.
  - `fp` — отпечаток данных (числа огрублены `_coarse`, чтобы колебания цен не пробивали кэш);
  - `structural` — состав бумаг + хэш промпта (`subjects_fingerprint`): если изменился (или отсутствует в
    старой записи), интервал `min_interval_h` не держит;
  - `force` (кнопка «ИИ») игнорирует интервал, но одинаковый запрос повторно не шлёт.
- **Фолбэки OpenRouter**: для `:free`-модели в тело добавляется `models: [основная, ещё 2 рекомендуемые]` —
  помогает при перегрузке провайдера, но расходует тот же дневной лимит.
- **Промпты** на русском, «оценка, не рекомендация». Кандидаты скринера оцениваются все: при отсутствии прямых
  новостей — по отраслевому контексту, с пометкой «по отрасли:» в `note`.
- Промпт для ChatGPT (`docs/CHATGPT_PROMPT.md`) и импорт стратегии связаны: пример YAML из промпта обязан
  проходить `strategy.import_strategy` — это проверяет тест.
