# Интерфейс (PySide6)

- **Воркеры.** Сеть и тяжёлое — только в `QThread`. Новый атрибут-воркер окна добавляй в `MainWindow.WORKERS`:
  `closeEvent` вызывает у них `requestInterruption()`, ждёт до 8 с и затем `terminate()`. Без этого — SIGABRT при
  выходе. Воркеры диалога настроек дожидаются в `SettingsDialog.closeEvent`. В цикле воркера проверяй
  `isInterruptionRequested()`.
- **Конвейер загрузки.** Портфель → свечи → новости → скринер → ИИ; статус шагов в правом углу статус-бара
  (`pipeline_step`). Старт с диска (`load_from_disk`) показывает снапшот, свечи, новости, сводки и кэш скринера
  без сети; сеть идёт, только если снапшот старше интервала обновления.
- **Не обнуляй панели при пересчёте.** Показывай прошлый контент и `panel.spinner.start(...)` / `.stop()`.
- **Режим «глазик»** (⌘⇧H, `act_privacy`): любые новые суммы в UI обязаны уважать его (`mask_text`,
  `hide_values` у графиков). Проценты можно показывать.
- **Геометрия.** Размер окна, разделители и вкладка сохраняются через `QSettings("PortfolioCheck", ...)`.
  У каждого `QSplitter` должен быть уникальный `objectName`, у тулбара — тоже (`saveState`).
- **Формы.** Многострочные пояснения — `AutoHeightLabel`; скрыть строку формы — `form.setRowVisible(widget, on)`;
  поле, которое должно тянуться, — `QSizePolicy.Expanding`. `_note()` в настройках даёт метку с
  `Ignored`-шириной и минимумом 200 px — для длинного текста внутри формы не годится.
- **Таблицы сортируются пользователем**: цвет и подсказки ячеек привязывай к ключу строки (тикеру), а не к индексу.
- **Иконки вместо слов** там, где это экономит место: тональность ▲ ■ ▼ (цвета `ai.SENT_COLOR`), выводы ✓ ✕ ⚑,
  всегда с подсказкой (`setToolTip` / `title=`).
- **Мастер первого запуска** открывается, только если `needs_setup()`: нет `setup_done` и нет `instruments`.
  Существующие конфиги мастер трогать не должен.
- Для ручного осмотра без macOS: `QT_QPA_PLATFORM=offscreen` и `widget.grab().save("x.png")`.
