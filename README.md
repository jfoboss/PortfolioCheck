# PortfolioCheck
Настольное приложение для macOS, которое сверяет портфель в Т-Инвестициях с твоими собственными правилами: целевыми долями классов активов, лимитами на эмитентов, правилами добора — и подсвечивает отклонения. Плюс тепловые карты, новости по твоим бумагам, скринер дивидендных идей и калькулятор «иду ли я по плану».
