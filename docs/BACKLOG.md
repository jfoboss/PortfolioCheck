# Бэклог

Приоритет — сверху вниз. Перед началом крупного пункта уточни у пользователя: решения по продукту принимает он.

## Ближайшее

1. **Режим `--demo`.** Запуск на `demo_snapshot.json` без токена и без записи в реальный конфиг — для
   скриншотов README и для проверки UI. Хранилище — временный каталог.
2. **Сохранять `RATE_BLOCK_UNTIL` на диск** (сейчас только в памяти): после перезапуска приложение один раз
   снова упирается в дневной лимит.
3. **Удалить мёртвый код** `portfolio_check.buy_side_yield` (заменён `new_money_yield`).
4. **Миграция конфигов при изменении дефолтов.** Ввести `config_version` и явные миграции, чтобы удаление
   дефолтов из кода не стирало данные существующих пользователей (случай с чёрным списком скринера).
5. **`check_private.sh`: предупреждать о картинках** в репозитории (содержимое не проверяется).

## Качество

6. **Разрезать `app.py` (~2000 строк)**: воркеры → `workers.py`, экраны → `screens/`. Без изменения поведения,
   под защитой тестов.
7. **Тесты**: `SettingsDialog.collect()` туда-обратно, `news.fetch_news` с подменой сети,
   `screener.apply_filters`, `forecast` при нулевых/отрицательных параметрах.
8. **Проверка рекомендаций ИИ**: короткий JSON-тест выбранной модели (по кнопке, с учётом лимита), вместо
   только эвристики `GOOD_FAMILIES`.

## Крупное (решение за пользователем)

9. **Нативный UI на SwiftUI**: сначала вынести ядро за JSON-API (CLI или локальный сервер), затем UI.
10. **Подпись Developer ID и нотаризация** вместо ad-hoc — чтобы у других пользователей не было «правый клик →
    Открыть».
11. **Другие брокеры** — только через отдельный слой источников данных; сейчас всё завязано на T-Invest.
