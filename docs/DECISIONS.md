# Решения

Формат: что решили → почему → что отвергли. Новые решения дописывай в конец.

1. **PySide6 (Qt) + Python, а не Tauri/SwiftUI.** Быстро развивать, ядро на Python уже было. Tauri не даёт
   нативного UI (WKWebView). Для «настоящего» macOS-вида нужен SwiftUI — отложено; путь туда: вынести ядро
   (≈70% кода не зависит от Qt) за JSON-API и писать новый UI поверх (см. BACKLOG).
2. **Keychain через `/usr/bin/security`, а не `keyring`.** В собранном .app `keyring` давал `SecAuthFailure`
   и лишние запросы доступа; системная утилита подписана Apple и стабильна. Секреты кэшируются на сессию.
3. **Фундаментал и дивиденды — T-Invest, не MOEX ISS.** ISS убрал `/securities/{t}/dividends`;
   `GetAssetFundamentals` отдаёт капитализацию, дивдоходность (в т.ч. средняя за 5 лет), долг/EBITDA, ROE,
   free float по всей вселенной TQBR за несколько запросов.
4. **Всё с диска сразу, сеть — догрузка.** Приложение открывается мгновенно; любой экран показывает последнее
   известное состояние, пока идёт обновление.
5. **ИИ — опционален и дёшев.** Без ключа панели скрыты. Кэш по отпечатку данных + интервал + «структурный»
   отпечаток; все сводки экранов — одним запросом. По умолчанию — бесплатная модель OpenRouter, выбранная из
   живого каталога (зашитый id однажды исчез).
6. **Доходность новых денег — по целевым долям, включая золото с нулём.** Пополнения распределяются по
   коридорам; считать только платящую часть — завышать доход (разница была 12,3% против 8,9%).
7. **Переоценка — рост цен по классам, взвешенный по целевым долям; по умолчанию CAGR за 5 лет;
   автоподстановка выключена по умолчанию.** Один год слишком случаен; факт прошлого — не прогноз.
   Классы без данных исключаются, а не считаются нулём.
8. **Год цели считается до 50 лет независимо от горизонта графиков.** Иначе цель «за горизонтом» выглядела как
   «не считается».
9. **Исходники нейтральные, личное — только в конфиге пользователя.** Один код для автора и для других
   пользователей; `scripts/check_private.sh` сверяет исходники с рабочим конфигом автора перед публикацией.
10. **Принципы стратегии сформулированы своими словами**, без бренда источника вдохновения — в публичном
    репозитории это выглядело бы как аффилиация.
11. **Мастер первого запуска + шаблоны + импорт YAML от ChatGPT** вместо длинной анкеты в коде: пользователь
    может собрать стратегию с моделью в диалоге и загрузить файл; импорт валидирует классы и совместимость
    коридоров.
12. **Иконки вместо подписей там, где это принято в терминалах**: ▲ ■ ▼ для тональности и изменения, ✓ ✕ ⚑
    для выводов — всегда с подсказкой.
13. **Версия конфига и явные миграции вместо дефолтов «на лету».** Раньше отсутствующий ключ означал «возьми
    дефолт из кода» — удаление дефолта стирало данные (чёрный список скринера). Теперь `config_version` +
    пошаговые миграции в `config_migrate.py`; значения старых дефолтов в миграции заморожены копией, перед записью
    остаётся `.bak`. Отвергнуто: хранить дефолты в коде вечно (тянет личное в публичный репозиторий) и
    мигрировать молча без копии (ошибку миграции нечем было бы откатить).
14. **Windows — на том же PySide6, первая версия без подписи кода.** Порт стоил ~35 правок (папки, секреты,
    бандл сертификатов без openssl, подписи сочетаний), переписывание UI — недели. На Windows секреты — через
    `keyring` (Credential Manager): причина, по которой `keyring` отвергнут на macOS (подпись бандла), там не
    действует. Проверка — CI на трёх ОС и запуск собранного `.exe --demo`. Отвергнуто: Electron/Tauri сейчас
    (см. `docs/CROSS_PLATFORM.md`), ядро за API (п. 9 — нет второго потребителя).
15. **Linux — тем же путём, что Windows**: `build.py` общий для Windows и Linux (onedir + zip / tar.gz), секреты —
    `keyring` → Secret Service с запасным файлом 0600, папка — `$XDG_DATA_HOME`. Формат — tar.gz с `.desktop` и
    `install.sh` (без sudo). Сборка на ubuntu-22.04 — старее glibc, запускается на большем числе дистрибутивов.
    Отвергнуто пока: AppImage / Flatpak / deb (дополнительный инструментарий без явной потребности).
