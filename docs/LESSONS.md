# История ошибок

Причины, а не симптомы. Перед правками в модуле просмотри его раздел. Многие случаи закрыты тестами
(помечены «Регресс:» в `tests/`).

## Сборка, система

- **Keychain `SecAuthFailure` в собранном .app** — `codesign` выполнялся до правки `Info.plist`, подпись
  становилась невалидной. Порядок исправлен; `keyring` заменён на `/usr/bin/security`.
- **SIGABRT при выходе** — уничтожался живой `QThread`. Все воркеры перечислены в `MainWindow.WORKERS`;
  `closeEvent`: `requestInterruption` → `wait(8000)` → `terminate`.
- **DMG не собирался** — `set -e` + `grep` без совпадений (код 1); позже — отсутствие сертификата.
- **PermissionError к iCloud Drive** — TCC; работаем локально и показываем баннер со ссылкой в настройки.
- **Настройки шире экрана** — длинные подписи в `QFormLayout`; решено `_note` с `Ignored`-шириной.
- **Настройки снова шире экрана (v1.4)** — 12-я вкладка «Оповещения»: на macOS строка вкладок не прокручивается,
  и окно не может быть уже суммы вкладок; плюс флажки с длинными подписями (флажки не переносят текст). Разделы —
  списком слева (`SettingsDialog.nav`), страницы в прокрутке, пояснения — в подсказках. Тест
  `test_settings_layout.py` (шрифт 13 px, как на macOS).
- **Все сайты — CERTIFICATE_VERIFY_FAILED в dmg из CI** (RSS, ISS, ЦБ, OpenRouter; T-Invest работал) —
  `ssl.create_default_context()` ищет корни по путям OpenSSL, зашитым при сборке Python: у CI это папка
  setup-python на раннере GitHub, на Mac пользователя её нет. Сборка `build_mac.sh` на своём Mac работала — пути
  совпадали, поэтому ошибка всплыла только с релизным dmg. Теперь `net.system_context()`: truststore (хранилище
  ОС), запасной — certifi. Заодно: повтор с устаревшими шифрами в `news._fetch` не срабатывал никогда —
  `urlopen` заворачивает `SSLError` в `URLError`.

## Данные

- **Пустые «Ближайшие отсечки у кандидатов» на настоящих данных** — дата бралась из `ex_dividend_date`
  (`GetAssetFundamentals`), а это ПРОШЛАЯ отсечка. В демо даты были вымышленные будущие — тесты не ловили.
  Теперь ближайшая выплата — `GetDividends` при догрузке кандидатов (`payouts.next_payout`, кэш
  `cache/candidate_payouts.json`); в таблице «Идеи» колонка переименована в «Прошл. отсечка».
- **Сценарии пустые, календарь ЦБ пуст (v1.5 на Mac)** — cbr.ru у пользователя обрывал TLS по таймауту
  (`handshake operation timed out`), а сценарии требовали ОБА ряда. Теперь доллар — из T-Invest (USD000UTSTOM,
  тот же канал, что портфель), ЦБ — запасной; при одном ряде — однофакторные беты с подписью; ошибка сайта ЦБ
  показывается над календарём, а не только в логе.
- **«Загружаю историю за 5 г» при каждом обновлении, а переоценка «за 5 лет» считалась примерно за год** — три
  ошибки вместе: `fetch_candles` при непустом кэше догружал только хвост (назад — никогда), обычное обновление
  (400 дней) обрезало кэш до 410 дней, а решение «догрузить» принималось по СРЕДНЕЙ глубине, которая из-за молодых
  бумаг (ЗПИФ, недавние размещения) навсегда меньше базы. Теперь кэш держит до 6 лет, история догружается назад,
  а «уже спрашивали с такой даты» помнит `cache/candles_depth.json`; `load_cached` по умолчанию отдаёт ~400 дней,
  чтобы риск и история стоимости по-прежнему считались «за год». Урок: условие догрузки — по каждой бумаге и с
  памятью о том, что данных нет, а не по агрегату.
- **«Консенсус аналитиков недоступен: TypeError … unexpected keyword argument 'instrument_id'»** — вызов
  `get_forecast_by(instrument_id=uid)` написан по описанию API, а в SDK новые методы (GetForecastBy,
  GetAssetFundamentals, GetAssetReports) принимают только объект запроса: `get_forecast_by(GetForecastRequest(…))`.
  SDK в тестах нет, подмена клиента принимала что угодно — ошибку увидел только пользователь. Урок: новый вызов
  SDK сверяй с сигнатурой в `tinkoff/invest/services.py`, в тесте подменный метод — с той же сигнатурой. Заодно:
  без консенсуса SDK отдаёт пустой `ConsensusItem` с нулями, а не None — такой ответ = «консенсуса нет».

- **KeyError 'dividends' в ISS** — эндпоинт убран; переход на T-Invest.
- **Бесконечная догрузка свечей кандидатов** — перерисовка запускала догрузку, догрузка — перерисовку.
  Ключ набора `_enriched_key`, значения в `_ideas_month`.
- **«Загружено для 0 бумаг»** — кэш скринера без `uid`; версия кэша `tinvest2`.
- **Потеря месячных изменений при обновлении из кэша** — новые объекты без полей; значения держим по тикеру.
- **Переоценка +2,5% вместо реальной** — класс без свечей (золото) считался как 0%. Теперь исключается.
- **Доходность новых денег 12,3%** — игнорировалось золото в пополнениях; правильно ≈8,9% (по целевым долям).
- **Чёрный список скринера пропал у существующего пользователя** — дефолтный список удалили из кода при
  обезличивании, а в его конфиге список сохранён не был. Урок: удаляя дефолт из кода, проверяй миграцию
  существующих конфигов. Закрыто версией конфига и миграциями (`config_migrate.py`).
- **Сохранение настроек стирало `config_version`** (найдено при введении версий) — `SettingsDialog.collect()`
  собирает конфиг с нуля, и всё, чего нет в форме, пропадает. Версию пишет сам `collect()`; новые служебные
  ключи верхнего уровня проверяй на этот сценарий.

## Новости

- **К «Золоту» липли спортивные новости, к VTBR — «Единая лига ВТБ», к MOEX — всё «московское»** — алиас-основа
  «золот» ищется подстрокой (медали, «Золотая маска»), спорт никак не отсекался, а к явным алиасам добавлялось первое
  слово названия («Московская»). Теперь `news.refers`: спорт (`OFFTOPIC_WORDS`) — мимо, неоднозначные основы
  (`AMBIGUOUS_WORDS`) — только рядом с рыночным словом (с начала слова: «цен» ≠ «сцена»), при явных алиасах имя из
  названия не берётся. Одна проверка для ленты, «Идей» и карточки.
- **Мусор в ленте: посты smart-lab, служебные сообщения Мосбиржи, кино у фонда TECH, «&quot;», время 14:56 среди
  17:xx** — у smart-lab в описании весь пост блога (упомянутая бумага или «дивиденд» → привязка/макро); биржа
  упоминает себя в каждом сообщении («О начале торгов…» → MOEX); у фондов название из общих слов («Технологии»);
  заголовки не раскодировались из HTML; время показывалось в поясе ленты (Frank — UTC). Теперь `SOURCE_RULES`
  (smart-lab — только заголовок и без макро, moex.com — без самой MOEX и без макро), у ETF — только тикер и
  алиасы, `html.unescape`, время — `astimezone()`.
- **Пустые ленты и 1000+ техсообщений Мосбиржи** (проверка всех лент каталога, сентябрь 2026) — retail.ru отдаёт
  RSS с `xmlns` по умолчанию, и `root.iter("item")` его не видел (теперь имена без пространства имён); Forbes,
  Банки.ру, «Нефть и Капитал», БКС из облака отдают JS-проверку «вы не робот» — «Проверить» теперь так и пишет
  (с домашнего адреса часто проходит); у Агроинвестора, BigpowerNews, CRE ленты переехали, у «Энергетики и
  промышленности» и «РБК Недвижимость» — пропали. Мосбиржа отдаёт сообщения за два месяца: ценовые коридоры,
  размещения облигаций «Сбербанк КИБ» привязывались к бумагам — теперь только заголовок, техника отсекается
  (`SOURCE_RULES["moex.com"]["drop"]`), новости старше `MAX_AGE_DAYS` = 7 не показываются.
- **«Банк Санкт-Петербург» ловил все новости про банки** — ключ по первому слову; общие слова теперь только
  в словосочетании (`GENERIC_WORDS`).
- **Часть лент «нет элементов `<item>`»** — это Atom; парсер понимает оба формата.
- **SSL-ошибки RSS** — использовался бандл для T-Invest; RSS идёт с системными корнями, при устаревшем TLS —
  ослабленный контекст (публичные ленты, секретов нет).
- **403** — нужны браузерные заголовки; повтор с `Referer`.
- **Новости МТС, ВТБ, VK не привязывались к бумагам** — `build_keywords` отбрасывал все ключи короче 4 символов,
  включая явные алиасы. Алиасы теперь сохраняются, короткие ключи ищутся целым словом (`news.mentions`) — и в
  ленте, и в счётчике новостей у кандидатов скринера.

## ИИ

- **Кэш отдавал сводку без кандидатов** — интервал держал, хотя изменился состав бумаг / промпт. Введён
  `structural`; запись без него считается устаревшей.
- **Модель оценивала только бумаги с новостями** — промпт это требовал; кандидаты теперь оцениваются все
  (по отрасли, если прямых новостей нет).
- **429 на всех бесплатных моделях** — это дневной лимит аккаунта (50 запросов), а не перегрузка моделей.
  Разбор 429 по телу, блокировка до сброса, пакетный запрос вместо пяти.
- **После перезапуска приложение снова упиралось в дневной лимит** — блокировка жила только в памяти. Теперь
  `cache/ai_rate_block.json`, при старте `ai.load_rate_block()`.
- **Бесплатная модель по умолчанию исчезла** — OpenRouter снял её; модель по умолчанию теперь из каталога.
- **«Настройка модели не применяется: сводка идёт через openrouter/free и ругается на Decart»** — на экране была
  ПРОШЛАЯ сводка (сделанная, когда модель по умолчанию выбралась маршрутизатором `openrouter/free`), а свежий запрос
  к выбранной модели упал с 429 upstream; в тексте ошибки — провайдер из ответа, без имени модели. Теперь в ошибке
  модель запроса и запасные, в статусе — чья сводка осталась на экране; `openrouter/*` моделью по умолчанию не берётся.

## Интерфейс

- **Таблицы сортировали числа как строки** — «18,300» выше «192,000», «-7.3» выше «+10.8». Все таблицы через
  `_fill` теперь на `widgets.SortItem`: число в любом оформлении (▲, %, ₽, валюта, разделители тысяч) — числом,
  даты и текст — текстом.

- **Панели обнулялись на время пересчёта** — теперь старый контент + `BusySpinner`.
- **Размер окна не запоминался** — нет `objectName` у сплиттеров/тулбара.
- **Галочки автоподстановки не сохранялись** — ключ `price_growth_auto` вместо `price_growth_pct_auto`.
- **Выбор базы переоценки требовал ручного «прикуривания»** — при старте значение из кэша, догрузка в фоне.
- **«Опережение 0 ₽» при любых параметрах** — план зафиксирован сегодня; теперь честный текст.
- **Окно настроек замирало на «Проверить» (ИИ)** — запрос к модели шёл в UI-потоке. Теперь `CheckWorker`.
- **Пустое поле слева на странице «ИИ» (macOS)** — одна длинная подпись («Не пересчитывать чаще, чем раз в:») задаёт
  ширину колонки подписей всей формы, а на macOS подписи прижаты вправо: поля уехали на треть окна. Длинную подпись —
  в строку вместе с полем (`form.addRow(widget)`), не в колонку подписей; статус каталога — своей строкой.
- **Галочка «только бесплатные» перекрывалась** — многострочные метки в форме; `AutoHeightLabel`.
- **Поле модели возвращало старый выбор после ручного ввода** — сравнение с текстом поля вместо пункта.
- **Тест «завис»** — модальный мастер в offscreen-режиме ждал ответа; в тестах `exec` подменяется.
- **Графики налезали друг на друга на MacBook 14″** — рисовались в любую отведённую высоту: строки баров
  сжимались до 14 px (полоска получала отрицательную высоту), бублики рисовали легенду поверх соседнего, легенда
  линий лежала на самих линиях, подписи оси X слипались. Теперь `need_height()` по содержимому → `setMinimumHeight`,
  стопки графиков — в `widgets.scroll_wrap`, легенда линий — строкой над графиком, ось X прореживается по ширине
  подписей. Тест в `test_demo.py`: на окне 1300×720 ни один график не ниже нужной высоты.
