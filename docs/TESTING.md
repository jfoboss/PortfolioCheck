## Осмотр интерфейса без macOS

`app.py --demo` (или `demo.setup()` в коде) — вымышленный портфель во временной папке, без токена и сети;
свечи, новости, кандидаты скринера и история стоимости генерируются, все экраны заполнены. Тикеры портфеля и
кандидатов — реальные бумаги Мосбиржи (числа кандидатов условные), поэтому «Обновить» у ленты подтягивает настоящие
новости (RSS без токена), а с ключом, введённым в Настройки → ИИ (в демо — только до выхода), работают ИИ-сводки.
Каждая ИИ-сводка расходует общий дневной лимит OpenRouter.
Снимок окна — как в `tests/test_demo.py` (`DEMO_SCREENSHOT=/путь/shot.png pytest tests/test_demo.py`):

```python
w = MainWindow(cfg_path); w.show(); w.grab().save("/tmp/screen.png")
```

Скриншоты для README — только из демо; реальный портфель в репозиторий не попадает. Новые и изменённые картинки
`check_private.sh` перечисляет, пока их не отметят просмотренными (`--approve-images`).

## Ручная проверка на macOS (перед релизом)

1. `./build_mac.sh`, установить из `.dmg`, первый запуск — правый клик → «Открыть».
2. Чистый профиль (переименовать папку данных, удалить токен): открывается демо с кнопкой «Настроить…»; по ней —
   свой профиль и мастер, шаблон применяется, токен задаётся,
   после первого обновления бумаги классифицированы автоматически и подсвечены оранжевым.
3. Существующий профиль: мастер не открывается, данные на месте, чёрный список скринера сохранён; конфиг без
   версии получил `config_version`, рядом появился `config.yaml.v0.bak`, в логе — строки «миграция конфига».
4. Keychain: токен и ключ ИИ читаются без повторных запросов доступа.
5. «О программе → Проверить подключения»: T-Invest, ЦБ, RSS.
6. ИИ: сводки появляются; при исчерпанном лимите — понятное сообщение и время сброса.
7. Выход из приложения во время загрузки — без краша.
8. `scripts/check_private.sh` — чисто.
