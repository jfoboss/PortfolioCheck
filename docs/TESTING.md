# Тестирование

## Автотесты

```bash
pip install -r requirements-dev.txt     # в активированном .venv (macOS / Linux / Windows)
python -m pytest -q
```

- Qt в режиме `offscreen`, сеть запрещена фикстурой `no_network`, профиль (`HOME`, `USERPROFILE`, `APPDATA`,
  `XDG_DATA_HOME`) и `paths.data_dir()` подменены на временный каталог, системные хранилища секретов отключены
  (`tests/conftest.py`) — реальные данные и токены пользователя тесты не видят и не трогают.
- CI гоняет тот же набор на ubuntu, windows и macos; различия ОС проверяет `tests/test_platform.py`.
- Сеть в тесте — только подменой `urllib.request.build_opener` / функций модуля (примеры — `tests/test_ai.py`).
- Модальные окна подменяй (`SetupWizard.exec`), иначе тест зависнет.
- Демо-портфель — фикстура `demo_positions` (`demo_snapshot.json`), стратегия — `demo_cfg`.
- Исправил ошибку — добавь тест с «Регресс: что ломалось» в docstring.

## Осмотр интерфейса без живого экрана

`app.py --demo` (или `demo.setup()` в коде) — вымышленный портфель во временной папке, без токена и сети;
свечи, новости, кандидаты скринера и история стоимости генерируются, все экраны заполнены. Тикеры портфеля и
кандидатов — реальные бумаги Мосбиржи (числа кандидатов условные), поэтому «Обновить» у ленты подтягивает настоящие
новости (RSS без токена), а с ключом, введённым в Настройки → ИИ (в демо — только до выхода), работают ИИ-сводки.
Каждая ИИ-сводка расходует общий дневной лимит OpenRouter.
Снимок окна — как в `tests/test_demo.py` (`DEMO_SCREENSHOT=/путь/shot.png pytest tests/test_demo.py`):

```python
w = MainWindow(cfg_path); w.show(); w.grab().save("/tmp/screen.png")
```

Скриншоты для README — только из демо; реальный портфель в репозиторий не попадает. Новые и изменённые картинки
`check_private.sh` перечисляет, пока их не отметят просмотренными (`--approve-images`).

## Ручная проверка перед релизом

CI уже проверяет, что сборка каждой ОС собирается и запускается (`--demo`, 20 секунд). Руками — то, что CI не видит.

**macOS** (основная платформа):

1. `./build_mac.sh` или dmg из релиза, установить, первый запуск — правый клик → «Открыть».
2. Чистый профиль (переименовать папку данных, удалить токен): открывается демо с кнопкой «Настроить…»; по ней —
   свой профиль и мастер, шаблон применяется, токен задаётся,
   после первого обновления бумаги классифицированы автоматически и подсвечены оранжевым.
3. Существующий профиль: мастер не открывается, данные на месте, чёрный список скринера сохранён; конфиг без
   версии получил `config_version`, рядом появился `config.yaml.v0.bak`, в логе — строки «миграция конфига».
4. Keychain: токен и ключ ИИ читаются без повторных запросов доступа.
5. «О программе → Проверить подключения»: T-Invest, ЦБ, RSS.
6. ИИ: сводки появляются; при исчерпанном лимите — понятное сообщение и время сброса.
7. Выход из приложения во время загрузки — без краша.
8. `scripts/check_private.sh` — чисто.
9. Меню приложения: «О программе PortfolioCheck», «Настройки…» (⌘,), «Завершить» — на месте.

**Windows** — распаковать zip из релиза: SmartScreen → «Выполнить в любом случае»; демо при первом запуске;
токен сохраняется в диспетчере учётных данных (Панель управления → Диспетчер учётных данных → Учётные данные
Windows → `portfolio-check`); масштаб 125/150 % — подписи не обрезаны; F5 и Ctrl+R обновляют.

**Linux** — распаковать tar.gz, `./PortfolioCheck/install.sh` → ярлык в меню приложений; токен — в Secret Service
(GNOME «Пароли и ключи» / KWallet), без него — предупреждение и файл 0600; X11 и Wayland.
